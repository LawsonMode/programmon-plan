The campaign, town by town

Programming grows from switches to blocks to Python across five towns. Each town adds its own standards missions.

The security storyline: the Null Crew

A band of prankster hackers links the security missions so each lesson has a reason to happen. The tone is mischief, not menace.

Sequence Citya fake gate inspector scrambles critters (SC-2) → Logic Junctionthe town debates monitoring traffic to catch them (LJ-2) and they try a fake Link Call (LJ-4) → Python Heightsan AI watchdog finds them after first flagging an innocent classmate (PH-3); stolen credits are returned

Two missions to know first

SC-2 · Sequence CityChad's idea

The Gate Inspector

  1. At the town gate, an official-looking "League Network Services" worker asks for your critter's IP address and link code. The pitch uses real scam signs: authority, urgency and a small reward.
  2. Share them and your critter is wiped and rewired, and some credits disappear. Refuse, or check with your helper first, and you watch another trainer get scammed and help rebuild their critter.
  3. Both paths lead to the Circuit Bench: re-seat the CPU, RAM and SSD, rewire the sensor-to-motor loop, and restore the program. A saved backup makes that instant.
  4. Then lock the doors: change the link code, close the unused port, add a firewall rule, install the firmware patch.

Why it's accurate: an IP address works like a street address. It tells someone where to knock, but the damage happens because a door was left unlocked: an open port, a default password, no firewall, an unpatched update. The scam works because the stranger is on the same town network. Nothing is lost for good; the credits come back when the crew is caught.

PH-2 · Python HeightsIn design doc, expanded

AI Rival Lab

  1. A rival critter learns your moves from your battle history, using a small model that runs offline and can show its reasoning.
  2. Students compare three ways to solve the same fight: step-by-step switches, rules they wrote in Python, and a model that learned from data. When is each the right tool?
  3. Train it on a lopsided history (you always BRACE) and it turns biased; fix it with more varied examples and a training/test split.
  4. The accuracy trap: "It predicts you 90% of the time" only because you BRACE 90% of the time.
  5. A twist: it was trained on classmates' replays without asking them. Should that data have been used?

Why it matters: this one mission reaches both essential AI standards in the course guidance and 20 of the 42 draft AI standards.

Rules every standards mission follows

  • Assess the action the standard names: compare, create, research, evaluate, explain. Playing a mission about a topic is not evidence.
  • Four steps per essential standard: introduction, guided practice, an independent task, and a later task in an unfamiliar situation, with a targeted retry.
  • Short evidence: a rule edit, a model, a policy with reasons, a source comparison, or a brief media piece.
  • Mastery records stay separate from credits, badges, unlocked towns and win rate.
  • Missions live in the world: resident requests, Link Calls and workshop tickets, not quiz screens.
  • Recovery is guaranteed: a mission can break a critter but never erases progress.
  • Simplified models and simulated results are labeled as simplified and simulated.

New in this build

  • Play Boot Borough: pick Blue or Gold, build a character, take the helper's first Link Call, choose a starter, battle Leo, pass Hiro's parts check for a CPU upgrade, beat Route 1 and the gym for the Boot Badge.
  • Battles run on real Python: the rules and every trainer's program are Python files, run in a sandbox. Pick a move each turn, or flip four switches into an autopilot.
  • Shops: Parts Mart (patch kits, an SSD upgrade) and Threads (free head coverings, clothes in any colour).
  • Bottom screen: BOTS, PARTS, CODE, MAP and DATA tabs, plus a START menu with items, save, options and help.
  • Help anytime: SELECT calls your helper for a hint that points at what to look at, never the answer.
  • Windows app: a portable exe that runs offline, sealed off from the internet, with saves in a folder beside it.
  • Learning record: which standards each objective touches, response timing, code runs, fixes and hints, kept in Quark's format beside the save. Nothing is shown in the game; Quark's teacher dashboard will read it.
