# Programmon Standards Plan

**Live page: https://lawsonmode.github.io/programmon-plan/**

How Programmon's planned missions cover Idaho's digital literacy course standards (Feb 2026), the draft 2026 digital literacy standards and the draft 2026 AI standards, plus the game's roadmap: patch notes, status, milestones and decisions.

Programmon is a 16-bit, Pokémon-style programming adventure for high-school digital literacy (Caldwell High School). Its source code is in a separate private repository; this repo holds only the published page.

`index.html` is generated (`npm run docs:publish` in the game repo). Don't edit it here; changes are overwritten on the next publish.
